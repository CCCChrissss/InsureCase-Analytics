# Local BGE Semantic Benchmark v1 中立判讀指南

## 1. 使用目的

本指南協助標註者理解 15 個查詢概念及 75 筆命中段落，但不提供任何題目的標籤答案，也不提供可直接貼入 `evidence_summary` 的完成句。

資料來源只包含：

- `outputs/local_bge_semantic_benchmark_v1_1000.json` 的原始 Local BGE 查詢結果。
- `backend/data/insurance_cases_local_bge_trial.db` 的命中 chunk 與相鄰 chunk。

本指南不使用歷史 Hugging Face 標註檔或評測報告。為降低錨定效應，內容不列模型分數與案件既有爭議類型。

方法透明度：整份指南由 Codex 依上述原始資料協助編寫，標籤仍由標註者自行決定。其中第 1 至 18 題在本指南建立前，標註者已於對話中接受逐題概念說明，因此這 18 題不能視為完全獨立盲標。若後續評估標註者一致性，這份標註結果應記錄為 AI 輔助標註，不能冒充未受提示的獨立基準答案。

## 2. 判讀方式

每題只根據命中 chunk 及必要的前後文回答下列問題：

1. 段落是否實質處理查詢概念，而非只出現相同字詞？
2. 查詢概念是本段主要問題、次要問題，還是只有背景關係？
3. 段落是否提供可摘要的原文證據？
4. 是否把相近但不同的概念混在一起，例如「不在承保範圍」與「除外責任」？

完成判斷後，再由標註者自行選擇標籤並用自己的文字撰寫理由。

## 3. 十五個查詢概念

| 查詢詞 | 判讀範圍 | 主要區分 |
| --- | --- | --- |
| 除外責任 | 保單一般除外條款、個別批註除外、故意行為或特定疾病不保 | 與「一開始不屬承保事故」或「未盡舉證責任」區分 |
| 必要性醫療 | 治療、住院、手術、藥物或醫材是否符合醫療常規且確有需要 | 與「確實接受醫療」及「保單是否列為給付項目」區分 |
| 癌症 | 癌症診斷、分期、治療、併發症及癌症保險給付 | 與只在病史中偶然提及癌症區分 |
| 住院 | 住院定義、必要性、期間、治療內容及住院相關給付 | 與門診、日間住院或單純生活照護區分 |
| 失能 | 失能狀態、等級、原因、認定日及失能相關給付 | 與短期不便、疾病診斷或一般住院區分 |
| 承保範圍 | 事故、疾病、治療或損害是否落入保單保障內容 | 與已在範圍內但適用除外條款，以及只爭執金額區分 |
| 違反告知義務 | 投保前詢問、告知內容、隱匿或遺漏及契約解除 | 與單純投保前已有疾病但沒有告知爭議區分 |
| 理賠金額 | 保險金計算方式、倍數、限額、日數及已付或應付差額 | 與是否具備請求資格的前置爭議區分 |
| 手術認定 | 某項處置是否屬保單定義的手術及適用哪一手術項目 | 與手術是否必要、住院是否必要區分 |
| 投保前疾病 | 保單成立前疾病是否已存在、有外表徵象及其理賠影響 | 與告知義務、等待期及保單停效期間疾病區分 |
| 保單停效 | 欠費停效、復效條件、保障恢復時間及事故發生時點 | 與一般等待期或契約原本未承保的事故區分 |
| 意外事故 | 外來性、突發性、偶然性、事故原因及傷害因果關係 | 與疾病內在原因、故意行為及單純受傷結果區分 |
| 條款怎麼解釋 | 條款文字意義、契約真意、疑義解釋及不同條款關係 | 與條款文義清楚後單純套用事實區分 |
| 業務招攬 | 招攬人員的說明、承諾、資訊揭露及銷售過程爭議 | 與理賠階段服務、一般客服或契約履行區分 |
| 豁免保費 | 因癌症、失能或其他約定事由免除後續保費的條件 | 與保險金給付、欠費停效及一般保費退還區分 |

## 4. 逐題中立提示

## 查詢詞：除外責任

### 第 1 題

- 案號：`113年評字第004957號`
- 段落焦點：減重手術是否具有醫療必要性，以及美容手術、外科整型的保單條款如何影響給付。
- 自行檢查：段落是否把某項具體條款列為本案爭點？拒絕給付是因治療不符合承保條件，還是因另有不保事由？
- 容易混淆：醫療必要性與美容手術不保是兩個可能同時存在但不同的判斷層次。

### 第 2 題

- 案號：`114年評字第004090號`
- 段落焦點：被保險人曾就腰椎疾病簽署個別聲明，後續腰椎治療是否落入聲明約定範圍。
- 自行檢查：本段是否解釋聲明的內容、效力及拒絕給付理由？爭議是否集中在排除範圍的廣狹？
- 容易混淆：保險法上投保前已有疾病，與雙方另行簽署的個別不保約定並不完全相同。

### 第 3 題

- 案號：`114年評字第002947號`
- 段落焦點：牙齒治療是否由外來突發事故造成，以及申請人是否完成意外事故與治療間因果關係的舉證。
- 自行檢查：拒絕給付是因適用某項特別不保條款，還是因事故未符合傷害保險的基本定義？段落提到「特約不保」時是否真的套用於本案？
- 容易混淆：「疾病原因被排除於意外定義之外」不必然等於保單另設的除外責任。

### 第 4 題

- 案號：`114年評字第001727號`
- 段落焦點：被保險人的死亡是否出於故意行為，以及保單對故意行為造成死亡的處理。
- 自行檢查：段落是否引用具體條款並把案件事實套入該條款？故意行為是承保事故定義的一部分，還是另外列出的不保原因？
- 容易混淆：事故是否具有意外性與故意行為條款可能同時被討論，應確認命中段落的實際重心。

### 第 5 題

- 案號：`114年評字第004090號`
- 段落焦點：申請人如何描述腰椎疾病聲明的簽署經過，以及保險公司如何以該聲明拒絕本次腰椎治療理賠。
- 自行檢查：即使這是申請人一方的陳述，是否仍完整呈現查詢概念的形成與爭議？本段與第 2 題是否提供不同角度的實質內容？
- 容易混淆：同一案件的不同 chunk 要分別判讀，不能因案件重複就直接沿用先前結論。

## 查詢詞：必要性醫療

### 第 6 題

- 案號：`114年評字第002461號`
- 段落焦點：微創手術中重複使用多種止血及促進傷口癒合醫材，是否符合一般臨床常規。
- 自行檢查：段落是否根據手術出血量、醫材功能重複及治療需求作出醫療判斷？還是只處理醫材是否在保單項目中？
- 容易混淆：費用是否屬保單列舉項目與醫材本身是否有必要，是兩個不同問題。

### 第 7 題

- 案號：`114年評字第005691號`
- 段落焦點：申請人主張長期住院由合法醫師判斷並確實接受診療，因此符合住院條件。
- 自行檢查：本段是在建立一般必要性判準，還是只陳述已辦理住院的事實？申請人提出哪些醫療風險支持長期住院？
- 容易混淆：醫師安排住院、實際住院與依一般醫療常規確有住院需要，並非必然相同。

### 第 8 題

- 案號：`114年評字第005691號`
- 段落焦點：評議理由如何以同專業醫師的一般判斷及實際照護內容，檢驗長期住院的合理性。
- 自行檢查：段落是否提出可普遍適用的住院必要性標準？是否把日常生活照護與積極住院治療加以區分？
- 容易混淆：這與第 7 題是同一案件，但命中的是不同立場與不同論證階段。

### 第 9 題

- 案號：`114年評字第002291號`
- 段落焦點：乳癌患者使用 Leuplin 荷爾蒙注射雖符合適應症，但是否需要以住院方式施打。
- 自行檢查：本段判斷的是藥物本身是否適合，還是住院方式是否必要？副作用、既往反應及門診可行性如何被使用？
- 容易混淆：治療有必要不代表為了該治療而住院也有必要。

### 第 10 題

- 案號：`114年評字第001504號`
- 段落焦點：子宮肌瘤手術使用的膠原蛋白敷料及血小板濃縮液分離管，是否為常規且必要的自費醫材。
- 自行檢查：段落是否依治療效果驗證、臨床常規及選擇性處置性質進行判斷？還是只因為自費就否定給付？
- 容易混淆：自費並不自動代表不必要，必須查看段落提出的醫療理由。

## 查詢詞：癌症

- 容易混淆：案件同時涉及癌症、復健與理賠次數，應依當前查詢概念判斷本段的內容比例。

### 第 13 題

## 查詢詞：承保範圍

### 第 26 題

- 案號：`113年評字第004576號`
