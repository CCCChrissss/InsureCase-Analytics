# Local BGE Semantic Benchmark v1 獨立標註指南

## 1. 適用範圍

本指南供第二位標註者判讀全量 `17254 candidates` 的 benchmark 結果。內容只定義共同標準，不包含個別案件提示、逐題摘要、模型相似度數值或第一輪答案。

第二位標註者不得在完成前查看：

- 第一輪標註快照。
- 第一輪評測報告。
- 舊版逐題 AI 輔助指南。
- 其他人對個別題目的標籤或證據摘要。

## 2. 標籤定義

### `relevant`（快捷鍵 `r`）

命中段落實質處理查詢概念，並提供足以說明該概念如何套用於案件的內容。概念可以是主要爭點，也可以是直接影響判斷的重要理由。

### `partially_relevant`（快捷鍵 `p`）

命中段落與查詢概念有實質關聯，但概念只占次要、背景或相鄰層次；單靠該段不足以完整回答查詢。

### `not_relevant`（快捷鍵 `n`）

命中段落沒有實質處理查詢概念。只有相同字詞、不同角色的同名義務、程序性敘述或不相同的相鄰概念，都不能只因文字相似而視為相關。

### 暫時略過（快捷鍵 `s`）

原文不足、概念不清或需要先確認一般名詞時，先略過，不要猜測。略過不是正式標籤，完成評測前仍須回頭處理。

## 3. 判讀流程

1. 只閱讀標註工具顯示的查詢詞、命中段落及必要的前後相鄰段落。
2. 先判斷段落是否實質處理查詢概念，再選擇標籤。
3. 不可依案件既有爭議類型直接決定答案；爭議類型只能作為來源資訊。
4. 不可因相似度較高就判定相關。
5. 同一案件若出現多個 chunks，必須逐段獨立判讀。
6. 選定標籤後，用自己的文字撰寫原文證據摘要。
7. 不確定時先略過，完成其餘題目後再處理。

## 4. 證據摘要規則

證據摘要應說明段落實際談了什麼，以及它與查詢概念的關係。摘要必須：

- 以命中段落或相鄰段落可確認的內容為依據。
- 使用自己的文字，不複製其他標註者的答案。
- 說明實質關係，不能只寫「有提到關鍵字」。
- 對部分相關或不相關項目，指出主要內容與查詢概念的差距。
- 不推論原文沒有提供的醫療或法律結論。

## 5. 十五個查詢概念

| 查詢詞 | 判讀範圍 | 主要區分 |
| --- | --- | --- |
| 除外責任 | 保單一般除外條款、個別批註除外、故意行為或特定疾病不保 | 與一開始不屬承保事故或未盡舉證責任區分 |
| 必要性醫療 | 治療、住院、手術、藥物或醫材是否符合醫療常規且確有需要 | 與確實接受醫療及保單是否列為給付項目區分 |
| 癌症 | 癌症診斷、分期、治療、併發症及癌症保險給付 | 與只在病史中偶然提及癌症區分 |
| 住院 | 住院定義、必要性、期間、治療內容及住院相關給付 | 與門診、日間住院或單純生活照護區分 |
| 失能 | 失能狀態、等級、原因、認定日及失能相關給付 | 與短期不便、疾病診斷或一般住院區分 |
| 承保範圍 | 事故、疾病、治療或損害是否落入保單保障內容 | 與已在範圍內但適用除外條款，以及只爭執金額區分 |
| 違反告知義務 | 投保前詢問、告知內容、隱匿或遺漏及契約解除 | 與保險人的說明義務、招攬揭露及單純投保前疾病區分 |
| 理賠金額 | 保險金計算方式、倍數、限額、日數及已付或應付差額 | 與是否具備請求資格的前置爭議區分 |
| 手術認定 | 某項處置是否屬保單定義的手術及適用哪一手術項目 | 與手術是否必要、住院是否必要區分 |
| 投保前疾病 | 保單成立前疾病是否已存在、有外表徵象及其理賠影響 | 與告知義務、等待期及停效期間疾病區分 |
| 保單停效 | 欠費停效、復效條件、保障恢復時間及事故發生時點 | 與一般等待期或契約原本未承保的事故區分 |
| 意外事故 | 外來性、突發性、偶然性、事故原因及傷害因果關係 | 與疾病內在原因、故意行為及單純受傷結果區分 |
| 條款怎麼解釋 | 條款文字意義、契約真意、疑義解釋及不同條款關係 | 與條款文義清楚後單純套用事實區分 |
| 業務招攬 | 招攬人員的說明、承諾、資訊揭露及銷售過程爭議 | 與理賠階段服務、一般客服或契約履行區分 |
| 豁免保費 | 因癌症、失能或其他約定事由免除後續保費的條件 | 與保險金給付、欠費停效及一般保費退還區分 |

## 6. 可接受的協助邊界

標註期間可以查詢一般名詞、操作方式及本指南中的概念定義，但不能在作答前取得個別題目的摘要、判斷方向或建議標籤。個別題目的討論應留到兩份標註都完成後，作為不一致項目的仲裁程序。

## 7. 完成條件

- 所有結果都有合法標籤。
- 所有結果都有非空白的原文證據摘要。
- 標註者名稱或代號已填寫。
- 完成前沒有查看第一輪答案。
- 完成後才執行一致率、Cohen's Kappa 與爭議項目比較。
